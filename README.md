# Q-POP-Diffraction
Simulate diffraction patterns from phase-field data.

## Acknowledgement
This development of the software was supported as part of the Computational Materials Sciences Program funded by the U.S. Department of Energy, Office of Science, Basic Energy Sciences, under Award No. DE-SC0020145.

## Installation
Dependencies:
1. cuFFT
2. GNU Make

On a system with a working CUDA installation, compile using the Makefile in the base directory of the repo. The compiled executable will be placed in the same directory. 

## Usage
For instructions on how to use this tool, please refer to the documentation on the website (q-pop-diffraction.pages.dev).
